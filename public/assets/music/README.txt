# Custom Music for Shruthi's Birthday Website 🎵

You can easily replace the background music with your own favorite song for Shruthi:

1. Place your audio file in this folder and name it:
   `birthday.mp3`
   (Full path: `/public/assets/music/birthday.mp3`)

2. Supported formats: .mp3, .m4a, .wav, .ogg

3. The website will automatically detect your custom audio file!
   If no custom file is added, the website automatically plays an enchanting
   crystal music-box romantic instrumental synthesized via Web Audio API.

4. You can also upload any audio file directly from your browser inside the
   music player bar at the top of the website!
